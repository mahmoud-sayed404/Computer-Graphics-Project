# =========================================
# Car Game - OpenGL GLUT Project
# =========================================

# Project Idea:
# This project is a simple car animation game
# built using OpenGL and GLUT.
# The car moves left and right while houses
# move in the background to simulate motion.

# =========================================
# Features
# =========================================
# - Car movement using arrow keys
# - Car scaling (zoom in / zoom out)
# - Rotating wheels animation
# - Pause / Resume system
# - Scene reset
# - Moving houses background animation
# - On-screen controls and information

# =========================================
# Controls
# =========================================
# Right Arrow  -> Move car right
# Left Arrow   -> Move car left
# +            -> Increase car scale
# -            -> Decrease car scale
# S            -> Pause / Resume
# R            -> Reset scene
# ESC          -> Exit program

# =========================================
# Technologies Used
# =========================================
# - C++
# - OpenGL
# - GLUT

# =========================================
# Main Functions
# =========================================

# drawRect()
# Draws rectangles such as the road and car body

# drawTriangle()
# Draws triangular shapes like the house roof

# drawText()
# Displays text on the screen

# drawHouse()
# Draws a complete house

# drawCar()
# Draws the car and rotating wheels

# display()
# Renders the entire scene:
# background, road, houses, car, and text

# update()
# Handles animation updates:
# - Wheel rotation
# - House movement
# - Screen refreshing

# keyboard()
# Handles normal keyboard input

# specialKeys()
# Handles arrow key movement

# init()
# Initializes OpenGL settings

# =========================================
# Animation System
# =========================================
# The project uses:
# glutTimerFunc()

# to update animation every 16ms
# which gives approximately 60 FPS.
